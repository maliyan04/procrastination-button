# 🛑 Procrastination Button

**Live Demo:** [https://maliyan04.github.io/procrastination-button/](https://maliyan04.github.io/procrastination-button/)

A fun, single-page web app that gives you random, useless tasks to do when you don't feel like working. Built with vanilla HTML, CSS, and JavaScript.

## ✨ Features
- **Splash Screen:** A 2-second "An Aliyan Production" intro animation.
- **Random Task Generator:** Click the button to get a random distraction (e.g., "Count how many browser tabs you have open").
- **Procrastination Counter:** Keeps track of how many times you've avoided work today.
- **Developer Page:** Built-in developer profile page.
- **Fully Responsive:** Works great on both mobile and desktop.

## 🛠️ Tech Stack
- HTML5
- CSS3 (Flexbox, Animations, Gradients)
- Vanilla JavaScript (DOM Manipulation)
